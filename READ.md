# Network Security Implementation Using Cisco Packet Tracer

## Project Overview

This project focuses on designing and implementing a secure enterprise network infrastructure using Cisco Packet Tracer. It demonstrates network security concepts and configurations designed to protect internal resources, control network access, and improve overall network security.

The project focuses on implementing multiple layers of network security to address common cybersecurity threats in an enterprise environment.

## Project Objectives

- Design a secure enterprise network architecture.
- Implement network segmentation using VLANs.
- Configure Access Control Lists (ACLs) to restrict unauthorized access.
- Implement centralized authentication using AAA and RADIUS.
- Configure secure VPN connectivity.
- Isolate public-facing services using a DMZ.
- Protect sensitive payment-related systems through network segmentation.
- Improve network access control and security management.

## Technologies and Security Concepts

## Security Implementations

### 1. VLAN Segmentation
Separated network departments and sensitive systems into different VLANs to reduce unauthorized communication and lateral movement.

### 2. Access Control Lists (ACLs)
Configured access restrictions to control traffic between network segments.

### 3. AAA and RADIUS Authentication
Applied centralized authentication and access control for administrative access.

### 4. VPN Security
Focused on secure remote connectivity and VPN access control.

### 5. DMZ Configuration
Designed network isolation for public-facing services.

### 6. Payment VLAN Security
Separated payment-related systems to provide additional protection for sensitive resources.

### 7. Guest Network Isolation
Restricted guest network access to internal enterprise resources.

## Threats Addressed

The project considers several enterprise network security threats, including:

- Branch ransomware and lateral movement.
- Unauthorized remote VPN access.
- Unauthorized administrative access.
- Guest network access to internal systems.
- BYOD device compromise.
- Third-party payment system compromise.
- Unauthorized physical access.
- Network configuration recovery failures.
